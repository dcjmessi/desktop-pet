桌面宠物工坊 - Windows 免安装版

使用方法
1. 将整个 DesktopPetWorkshop 文件夹复制到目标电脑。
2. 双击 DesktopPetWorkshop.exe。
3. 首次启动会在程序旁创建 data 文件夹，用来保存设置。

系统要求
- Windows 10/11 64 位
- 无需安装 Python

互联网联机
- 默认 TCP 端口：38475
- 主机需要在路由器配置端口转发，并允许 Windows 防火墙访问。
- 主机与客户端填写相同的临时连接口令。
- 消息和动作使用端到端加密。

注意
- 不要只复制 EXE，必须复制整个文件夹。
- 发布包不包含原电脑的设置、密钥和已有照片宠。
- 默认宠物素材仅供个人学习，请勿商用分发。
