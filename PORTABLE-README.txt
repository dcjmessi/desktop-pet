桌面宠物工坊 - Windows 免安装版

使用方法
1. 将整个 DesktopPetWorkshop 文件夹复制到目标电脑。
2. 双击 DesktopPetWorkshop.exe。
3. 首次启动会在程序旁创建 data 文件夹，用来保存设置。

系统要求
- Windows 10/11 64 位
- 无需安装 Python

互联网联机
- 主机先在花生壳创建 HTTP/HTTPS 映射，内网端口设为 38475。
- 主机在工坊填写映射地址并创建邀请码，再把邀请码发给好友。
- 好友粘贴邀请码并点击“加入邀请码”，无需配置路由器端口转发。
- 聊天和动作数据使用端到端加密。
- 花生壳是否支持当前映射透传 WebSocket，需要以实际联机测试为准。

注意
- 不要只复制 EXE，必须复制整个文件夹。
- 发布包不包含原电脑的设置、密钥和已有照片宠。
- 默认宠物素材仅供个人学习，请勿商用分发。
